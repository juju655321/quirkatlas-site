# Self-hosted fonts for Quirk Atlas

These files are downloaded from the Google Fonts / fonts.gstatic.com versions of two SIL Open Font License (OFL 1.1) families. They are bundled with the site so headings and body text do not depend on a third-party font CDN.

## Fraunces

- Designer: Undercase Type (Spencer Charles, Flavia Zimbardi, and others)
- License: SIL Open Font License 1.1 (see `OFL-Fraunces.txt`)
- File: `Fraunces-latin-variable.woff2` (variable, weight 400–700, opsz 9–144, Latin)
- Upstream: https://fonts.google.com/specimen/Fraunces
- Used for: the Quirk Atlas wordmark and headings

## Source Sans 3

- Designer: Paul D. Hunt, with the Source Sans team at Adobe
- License: SIL Open Font License 1.1 (see `OFL-SourceSans3.txt`)
- File: `SourceSans3-latin-variable.woff2` (variable, weight 400–700, Latin)
- Upstream: https://fonts.google.com/specimen/Source+Sans+3
- Used for: body text, UI labels, and place cards
